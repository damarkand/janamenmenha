# JanaMen — Digital HR

Корпоративный портал для сотрудника, руководителя и HR. Всё работает на одном компьютере: сайт, сервер, база данных и нейросеть Qwen2.5-3B. Интернет нужен только при первой установке.

**Что умеет**

- **Главная** — сводка и графики: рабочие часы, задачи, обучение, ближайшие даты.
- **Задачи** — доска «К выполнению / В работе / Готово». Руководитель ставит задачи своей команде.
- **График** — рабочий календарь на месяц: праздники, отпуска, сроки задач, отметка часов.
- **Заявки** — отпуск, аванс, справки, согласование руководителем.
- **Обучение** — курсы, прогресс, тесты.
- **AI Ассистент** — чат с нейросетью. Отвечает только по базе знаний компании и указывает источник. Если ответа нет, предлагает передать вопрос HR.
- **Команда** (руководитель и HR) — загрузка сотрудников и заявки на согласование.
- **Профиль** и **Уведомления**.

Вкладки общие для любой профессии: разработчик, бухгалтер, продажи, HR.

## 1. Запуск одной командой

Откройте Терминал в папке проекта и выполните:

```
chmod +x start.sh run_tests.sh
./start.sh
```

Скрипт сам:

1. создаёт окружение `.venv` и ставит зависимости;
2. ставит движок нейросети `llama-cpp-python`. В первый раз он собирается **5–15 минут**, это нормально;
3. скачивает модель Qwen2.5-3B (**около 2 ГБ**). При обрыве связи просто запустите скрипт ещё раз, загрузка продолжится;
4. запускает сервер и открывает сайт в браузере.

Повторные запуски занимают несколько секунд.

Если нужно запустить быстро, без нейросети (ассистент будет отвечать цитатами из базы знаний):

```
chmod +x start.sh run_tests.sh
./start.sh --no-ai
```

Остановить сервер: `Ctrl+C`.

На Windows вместо `./start.sh` запустите `start.bat`.

> Если macOS попросит установить «инструменты разработчика», согласитесь или выполните `xcode-select --install`, затем снова `./start.sh`. Они нужны, чтобы собрать движок нейросети.

## 2. Старый способ запуска (работает как раньше)

```bash
cd ~/Downloads/janamen-backend
source .venv/bin/activate
uvicorn app.main:app --reload --port 8000
```

Чтобы при таком запуске работала нейросеть, один раз выполните:

```bash
CMAKE_ARGS="-DGGML_METAL=OFF" pip install -r requirements-ai.txt
python scripts/download_model.py
```

Без этого ассистент тоже работает, но отвечает цитатами из базы знаний.

## 4. Как проверить, что всё работает

**Шаг 1. Сервер.** Откройте http://localhost:8000/health. Должно быть:

```json
{"status": "ok", "storage": "sqlite", "assistant_mode": "qwen", "ai_loaded": true, ...}
```

- `assistant_mode: "qwen"` — нейросеть подключена.
- `ai_loaded: true` — модель загружена в память. Сразу после старта здесь может быть `false`: загрузка занимает 10–30 секунд.
- `assistant_mode: "extractive"` — нейросеть не установлена или выключена. Ассистент работает, но отвечает цитатами.

**Шаг 2. Сайт.** Откройте http://localhost:8000 и войдите как `employee@janamen.kz`. Пройдитесь по вкладкам:

- **Главная** — карточки и четыре графика.
- **Задачи** — нажмите «Новая задача», создайте её, затем нажмите «В работу». Карточка переедет в соседнюю колонку.
- **График** — выберите прошедший рабочий день и нажмите «Отметить часы». Цифры в календаре обновятся.
- **AI Ассистент** — вверху должен гореть зелёный значок «Qwen2.5-3B готова». Спросите «Как перенести отпуск?»: ответ печатается по ходу, внизу указан источник. Спросите «Какой дресс-код в офисе?»: ассистент честно скажет, что ответа нет, и предложит передать вопрос HR.

**Шаг 3. Руководитель.** Выйдите и войдите как `manager@janamen.kz`. Появится вкладка **Команда**: там видны сотрудники и заявки, которые можно одобрить прямо со страницы.

**Шаг 4. Автотесты.** В другом окне терминала, в папке проекта:

```bash
./run_tests.sh
```

В конце должно быть `passed` без `failed`. Тесты не трогают вашу базу и не загружают нейросеть, поэтому идут быстро.

## 5. Нейросеть

- **Модель:** Qwen2.5-3B-Instruct, файл `models/qwen2.5-3b-instruct-q4_k_m.gguf`. Скачивается скриптом `scripts/download_model.py` с Hugging Face.
- **Как работает:** модель запускается **внутри сервера** через Python-библиотеку `llama-cpp-python`. Ollama, LM Studio и другие отдельные программы не нужны.
- **Что ей нужно:** около 2,5 ГБ оперативной памяти, видеокарта не нужна. На MacBook Pro 2017 модель работает на процессоре: ответ появляется через 10–40 секунд и печатается по мере генерации.
- **Почему она не выдумывает:** сначала сервер ищет подходящие разделы в базе знаний. Если их нет, нейросеть вообще не вызывается, и ассистент сразу говорит, что ответа нет. Если разделы есть, модель видит только их и обязана указать источник.
- **Личные вопросы** («сколько у меня дней отпуска?», «какие у меня задачи?», «сколько часов я отработал?») берутся из ваших данных, без нейросети.
- **Настройки** задаются переменными окружения перед запуском, например `AI_THREADS=4 ./start.sh`:
  - `AI_MODE=off` — выключить нейросеть;
  - `AI_THREADS` — сколько ядер процессора отдать модели;
  - `AI_MAX_TOKENS` — длина ответа (меньше — быстрее).

  Все настройки перечислены в `.env.example`.

## 6. База данных

Данные хранятся в `digital_hr.db` (SQLite) через `database.py`. Ту же базу использует Telegram-бот, поэтому изменения видны и на сайте, и в боте. Файл `database.py` не изменялся. Всё новое (задачи, часы, графики работы, пароли, история заявок) лежит в отдельных таблицах с приставкой `api_`.

- **Начать демо заново:** остановите сервер, удалите `digital_hr.db*` и запустите снова. Демо-данные загрузятся автоматически.
- **Только в памяти, без файла базы:** `STORAGE=memory ./start.sh`.

## 7. Что где лежит

```
janamen-backend/
├── start.sh / start.bat     запуск одной командой
├── run_tests.sh             автотесты
├── database.py              база данных (общая с Telegram-ботом)
├── app/                     сервер (FastAPI)
│   ├── api/routes/          адреса API: задачи, график, заявки, ассистент…
│   ├── services/            логика; llm.py — нейросеть Qwen, assistant_service.py — ассистент
│   ├── repositories/        хранение: sqlite.py (база) и memory.py (память)
│   └── models/              модели данных
├── front/                   сайт (открывается на http://localhost:8000)
├── knowledge_base/          документы для ассистента (*.md)
├── data/                    демо-данные: сотрудники, задачи, курсы, праздники
├── models/                  сюда скачивается нейросеть
├── scripts/download_model.py
└── tests/                   автотесты
```

**Добавить документ для ассистента:** положите `.md`-файл в `knowledge_base/`. Каждый раздел начинается с `## Заголовок`. Строка `Ключевые слова: …` помогает находить раздел по разговорным формулировкам. После этого перезапустите сервер.

> Документы в `knowledge_base/` и праздники в `data/holidays.json` — демонстрационные. Перед реальным использованием замените их утверждёнными документами компании и сверьте с производственным календарём.

## 8. Если что-то не так

| Проблема | Что делать |
|---|---|
| `permission denied: ./start.sh` | Выполните `chmod +x start.sh run_tests.sh` или запустите `bash start.sh` |
| Не ставится `llama-cpp-python` | Выполните `xcode-select --install`, затем снова `./start.sh`. Пока можно работать с `./start.sh --no-ai` |
| Модель не скачивается | Запустите `python scripts/download_model.py` ещё раз, загрузка продолжится. Ссылка для ручной загрузки выводится в терминале |
| Ассистент отвечает медленно | Это нормально для старого процессора. Попробуйте `AI_MAX_TOKENS=160 ./start.sh` |
| `Address already in use` | Сервер уже запущен в другом окне. Закройте его или запустите на другом порту: `PORT=8001 ./start.sh` |
| Сайт показывает старые данные | Обновите страницу с `Cmd+Shift+R` |
